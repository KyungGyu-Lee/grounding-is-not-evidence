Failure rate is $1 - \mathrm{Ret(pred)}$, so the bottom-right of the first table reads off this one directly.

Two things to note before this goes in the table. **The IoU block is monotone where the IoP block is not**: retention rises across the three IoU bins in all four columns (by .05 to .07 from the bottom bin to the top), while the IoP block is flat or falls (NExT-GQA C3: .761, .809, .683). A reader comparing the two blocks will see that, so the caption should say which quantity each block bins. It does not weaken the sentence the block is there to support: even in the top IoU bin, 11.6% to 17.4% of predictions do not reproduce the full-video response. **Second, the NExT-GQA C3 top bin holds only N = 23 rows** — thin enough that .826 should not be read as a precise figure; the C2 columns (N = 121 and 280) are the ones the §6.3 sentence quotes.

The LaTeX block is `table_s3_iou_block.tex`: paste it into Table S3 (`tab:audit`) after the IoP block. It uses the same `\multicolumn{5}{@{}l}{\emph{...}}` heading row and `\quad` bin rows as the neighbouring IoP block rather than a bare `\textit{...} \\`, so it drops in without disturbing the column spec. Per-bin $N$ is carried in comment lines above the block.
